# Good Reads

## Possibly good reads

### Books

"Design Patterns: Elements of Reusable Object-Oriented Software" by Erich Gamma, Richard Helm, Ralph Johnson, John
Vlissides

    While not specific to C++ or event-driven architecture, this classic book covers the Observer pattern, a cornerstone of event-driven design. It provides a solid foundation for understanding event-driven concepts in an object-oriented context, with examples adaptable to C++.
    Why: Explains patterns like Observer and Mediator, which are critical for event-driven systems.

"C++ Concurrency in Action" by Anthony Williams

    This book focuses on concurrency in C++, including techniques for handling asynchronous events using threads, futures, and promises. It’s highly relevant for building scalable event-driven systems in C++.
    Why: Covers practical C++ concurrency mechanisms (e.g., std::async, std::future) that are often used in event loops and event-driven architectures.

"Modern C++ Design: Generic Programming and Design Patterns Applied" by Andrei Alexandrescu

    This book dives into advanced C++ techniques, including event-driven design patterns like the Reactor and Proactor patterns, using templates and generic programming.
    Why: Offers deep insights into building flexible, event-driven frameworks in C++ with modern techniques.

### Online Articles and Tutorials

    "Event-Driven Programming in C++" by Bartosz Milewski
        Available on Bartosz Milewski’s blog (search for his posts on C++ and concurrency).
        Why: Explains event-driven programming concepts in C++ with a focus on functional and concurrent paradigms, often with clear code examples.
    "Building an Event-Driven System in C++" (CppCon Talks)
        Check CppCon archives on YouTube or their website for talks like "Event-Driven Architecture in C++" or related concurrency sessions.
        Why: CppCon presentations often include practical C++ code and real-world applications of event-driven systems, presented by industry experts.
    "Introduction to Boost.Asio" (Boost Documentation)
        Available at boost.org.
        Why: Boost.Asio is a popular C++ library for asynchronous I/O and event-driven programming. The official documentation and tutorials provide practical examples for building event loops and handling events.

### Blogs and Community Resources

    Fluent C++ (fluentcpp.com)
        Jonathan Boccara’s blog has articles on modern C++ design patterns, including event-driven techniques and asynchronous programming.
        Why: Offers practical, C++-specific advice with a focus on clean, modern code.
    C++ Weekly by Jason Turner (YouTube and Blog)
        Look for episodes on asynchronous programming or event loops.
        Why: Provides concise, practical C++ tips, often touching on event-driven design and concurrency.

### Libraries and Tools

    Boost.Asio
        A C++ library for network and low-level I/O programming using an event-driven model.
        Why: Widely used for building event-driven applications in C++. Check tutorials on building an event loop with Boost.Asio.
    libuv
        A cross-platform asynchronous I/O library (used in Node.js) with C++ bindings.
        Why: Great for learning how event loops work in a C/C++ context, with examples applicable to event-driven architecture.
    libevent
        Another lightweight C library with C++ compatibility for event-driven programming.
        Why: Simple and efficient for building event-driven systems, with clear documentation.

### Practical Guides

    "Event-Driven Architecture with C++" (Medium or Dev.to)
        Search for articles on Medium or Dev.to with titles like “Event-Driven Architecture in C++” or “Asynchronous Programming in C++.”
        Why: These platforms often host developer-written tutorials with code snippets and real-world examples.
    GitHub Repositories
        Search for projects like “event-driven C++ framework” or “C++ event loop” on GitHub.
        Why: Open-source projects often include working examples of event-driven systems, such as custom event loops or message queues.

### Recommendations for Learning

    Start with Boost.Asio: If you’re new to event-driven programming in C++, begin with Boost.Asio tutorials. It’s widely used and has a robust community.
    Explore Design Patterns: Read about the Observer, Reactor, and Proactor patterns in the context of C++ to understand the theoretical underpinnings.
    Practice with Small Projects: Build a simple event-driven system, like a chat server or a message queue, using Boost.Asio or libuv to solidify your understanding.
    Check CppCon Talks: Search for event-driven or asynchronous programming sessions from CppCon for cutting-edge techniques and real-world applications.
